# 思考力パズル

『AIに奪われた思考力を取り戻す』— AIに頼りすぎて鈍った頭を、論理パズルで鍛え直すゲームです。

- 毎日1問（日替わり）、段階ヒントつきの論理パズル
- スコア: 基本100点 ＋ ヒントボーナス ＋ 時間ボーナス
- 週間リーグ（ブロンズ／シルバー／ゴールド／プラチナ）と連続記録（ストリーク）
- 記録はブラウザ内（localStorage）にのみ保存されます

公開ページ: https://numalab-jp.github.io/thinking-puzzle/

出題・文: 沼ラボ（note: https://note.com/numalab ）
問題の追加は `problems.js` に項目を足すだけです。
